遺伝子型に基づく表現型シュミレーション&GWAS

必要なファイル

  1. sampling_snp.R

  2. 360linesMAF0.05NA0.1_pruning.csv (独立したLDからSNPsを抽出するために、pruningした後の遺伝子型データ)

  3. simulation_pheno_by_geno.R

  4. GWASscript_array.R (アレイジョブ用)

  5. GWASscript_array.sh (アレイジョブ用, SHIROKANE用)

SNPのサンプリング

sampling_snp.Rで編集すべき箇所

以下の箇所で、設定をお願いします。

##################################

#同時に抽出するSNP数

n.qtn <- 20

#データセット数

n.dataset <- 1000

##################################

sampling_snp.Rを実行すればOKです

GWASはラップトップで十分動きます。上記設定で2,3分くらい。

出力ファイル

「QTN」フォルダに1000ファイル「数字_snp20info.csv」が出力される。

遺伝子型情報から表現型を算出する

「QTN」フォルダに入った1000ファイルを使います。

simulation_pheno_by_geno.Rで編集すべき箇所

以下の箇所で、設定をお願いします。

# lines 1-5

# 遺伝子型から仮想形質データ算出スクリプト

# 設定

QTNs <- 20     # how many qtns are set as causal genes

kmax <- 1000     # how many patterns of QTNs

#############################################



# lines 20-28

  # 遺伝子型ごとに表現型データ作成

  x[x == "0"] <- 1  　#遺伝子効果を設定

  x[x == "-1"] <- 0

  x[x == "1"] <- 2　　#遺伝子効果を設定

  # 出穂期は50日を基準とする

  day <- matrix(50, 1, ncol(x))  #基準を設定 #なくても統計量に関係しないはず

  # QTN効果の加算

  for (i in 1:QTNs){

    day <- day + x[i,] + runif(1*ncol(x), min=-1, max=1)　#ノイズ効果の設定

  }

出力ファイル

  1. Pheno.csv

GWASのアレイジョブ

“SHIROKANE”で「GWASscript_array.R」と「Pheno.csv」があるフォルダで「GWASscript_array.sh」をqsubすれば良い。

GWASscript_array.shの設定

-t 1-1000 #1000データの場合

#!/bin/bash

#$ -S /bin/bash

#$ -cwd

#$ -l s_vmem=70G

#$ -t 1-1000 #1000データの場合



module use /usr/local/package/modulefiles/

module load R



Rscript GWASscript_array.R ${SGE_TASK_ID}

出力ファイル

1000個のGWAS結果のリストが出力される。
時間はSHIROKANEの混雑状況次第。1000回GWASを投げると、早ければ3日、遅ければ2週間ほど。
