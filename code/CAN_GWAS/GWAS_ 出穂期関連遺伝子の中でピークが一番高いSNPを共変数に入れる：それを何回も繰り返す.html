GWAS: 出穂期関連遺伝子の中でピークが一番高いSNPを共変数に入れる：それを何回も繰り返す

必要なファイル

  1. CAN_GWAS.R

  2. 360linesMAF0.02NA0.3_7.vcf

  3. Geno_72HD.csv
    「360linesMAF0.02NA0.3_7.vcf」から既知出穂期72遺伝子のSNPsの遺伝子型をリストにしている。

  1. pheno.csv
    「pheno.csv」に表現型だけを入力しておく。

CAN_GWAS.Rで編集すべきところ

line2でGWASを何回繰り返すかを設定してください。今回は60.

# 設定

n <- 60 #何回繰り返し共変数を加えGWASするのか

Rを実行すればOKです

GWASはラップトップで十分動きます。
60回繰り返すと3, 4日かかります。

出力ファイル

フォルダごとに

  1. QK-Xqtn.csv (GWASの結果リスト)

  2. QK-Xqtn.pdf (マンハッタンプロット)

  3. QK-Xqtn_qqplot.pdf (QQplot)

  4. flowering_genes_Xcofactors.csv (既知遺伝子SNPsだけのGWAS結果)
