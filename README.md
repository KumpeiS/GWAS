# Genotype-based phenotype simulation and GWAS

This repository contains scripts and input files for genotype-based phenotype simulation and genome-wide association study (GWAS) analyses.

The workflow consists of the following three steps:

1. Sampling SNPs/QTNs from pruned genotype data
2. Simulating phenotypes based on genotype information
3. Performing GWAS using array jobs on SHIROKANE

---

## Overview of required files

The following files are required for this workflow.

| File | Description |
|---|---|
| `sampling_snp.R` | R script for sampling SNPs/QTNs from pruned genotype data |
| `360linesMAF0.05NA0.1_pruning.csv` | Pruned genotype dataset used to sample SNPs from relatively independent LD regions |
| `simulation_pheno_by_geno.R` | R script for simulating phenotypes based on genotype information |
| `GWASscript_array.R` | R script for GWAS analysis; designed for use with array jobs |
| `GWASscript_array.sh` | Shell script for submitting GWAS array jobs on SHIROKANE |

# 1. Sampling SNPs/QTNs

## Purpose

The script `sampling_snp.R` randomly samples SNPs/QTNs from a pruned genotype dataset.

The input genotype file is:

```text
360linesMAF0.05NA0.1_pruning.csv
```
Parameters to edit

Before running sampling_snp.R, edit the following section of the script.
```r
##################################
# Number of SNPs extracted simultaneously
n.qtn <- 20

# Number of datasets
n.dataset <- 1000
##################################
```
In the above example:

n.qtn <- 20 means that 20 SNPs/QTNs are sampled at the same time.
n.dataset <- 1000 means that 1,000 independent QTN datasets are generated.

How to run

Run the script in R:
```r
Rscript sampling_snp.R
```
The output files are generated in the QTN/ directory.

With the settings shown above, 1,000 files are generated:
```text
QTN/1_snp20info.csv
QTN/2_snp20info.csv
QTN/3_snp20info.csv
...
QTN/1000_snp20info.csv
```
Each file contains information for one sampled QTN set.

Expected runtime

This step can be run on a standard laptop computer.

With the following settings:
```r
n.qtn <- 20
n.dataset <- 1000
```

# 2. Simulating phenotypes from genotype information
## Purpose

The script simulation_pheno_by_geno.R simulates phenotype values based on genotype information.

This step uses the QTN files generated by sampling_snp.R.

Input files

The input files are the 1,000 QTN files in the QTN/ directory.

Example:
```text
QTN/1_snp20info.csv
QTN/2_snp20info.csv
QTN/3_snp20info.csv
...
QTN/1000_snp20info.csv
```

## Parameters to edit
Before running simulation_pheno_by_geno.R, edit the following section of the script.
```r
# Genotype-based virtual phenotype simulation script

# Settings
QTNs <- 20      # Number of QTNs set as causal SNPs
kmax <- 1000    # Number of QTN patterns
#############################################
```
In the above example:

QTNs <- 20 means that 20 QTNs are treated as causal SNPs.
kmax <- 1000 means that 1,000 QTN patterns are used.

The following section defines genotype effects, baseline phenotype value, and random noise.

```r
# Generate phenotype values for each genotype
x[x == "0"] <- 1    # Genotype effect
x[x == "-1"] <- 0
x[x == "1"] <- 2    # Genotype effect

# Heading date is set to 50 days as the baseline
day <- matrix(50, 1, ncol(x))  # Baseline value

# Additive QTN effects
for (i in 1:QTNs){
  day <- day + x[i,] + runif(1 * ncol(x), min = -1, max = 1)  # Noise effect
}
```

In this setting:

Genotype -1 has an effect of 0
Genotype 0 has an effect of 1
Genotype 1 has an effect of 2
The baseline phenotype value is 50
Random noise is added from a uniform distribution between -1 and 1
## How to run
Run the script in R:
```bash
Rscript simulation_pheno_by_geno.R
```
## Expected output
The script generates the following output file:
```text
Pheno.csv
```

Pheno.csv contains the simulated phenotype data.

Each column corresponds to one simulated phenotype dataset. Therefore, when kmax <- 1000, the file contains 1,000 simulated traits.

# 3. GWAS using array jobs on SHIROKANE
## Purpose
GWAS is performed using GWASscript_array.R.
The script is designed to run as an array job on SHIROKANE using GWASscript_array.sh.
## Required files
Place the following files in the same directory on SHIROKANE:
```text
GWASscript_array.R
GWASscript_array.sh
Pheno.csv
```
Pheno.csv is the output file generated by simulation_pheno_by_geno.R.

## How to submit the array job
Submit the job using qsub:
```bash
qsub GWASscript_array.sh
```
